# Sample model: Chesapeake Bay Bridge-Tunnel (IFC 4.3)

`chesapeake_bay_bridge_tunnel_4x3.ifc` is the "Chesapeake Bay Bridge-Tunnel IFC Model" from
buildingSMART's community sample files:
https://github.com/buildingsmart-community/Community-Sample-Test-Files/tree/main/IFC%204.3.2.0%20(IFC%204.3)/Chesapeake%20Bay%20Bridge-Tunnel%20IFC%20Model

- **Licence:** MIT, © 2026 buildingSMART Community Projects – see `LICENSE` next to this file.
- **Geometry and layout** are approximated from public information and **OpenStreetMap data
  (© OpenStreetMap contributors, ODbL)**.
- **Synthetic model**, made with parametric IfcOpenShell scripts to test model audits. It is not an
  as-built record and was not produced, reviewed or endorsed by the Chesapeake Bay Bridge and
  Tunnel District, VDOT or FHWA. Its properties are placeholders, and some errors are included on
  purpose. See the original description in `README.source.md`.
- The file is unchanged (SHA-256 `b7fcf20aa8f977aa66ea38e0d11ef982967103f76312841d9fe0ccd5f5d1158f`).

In Vispecta it is the second sample on the start screen (#41): 26 MB (about 5 MB to download, the
site sends it compressed), 17,553 elements, and two alignments of about 31 km – US-13 northbound
and southbound – so stations, cross sections and longitudinal profiles can be tried on a long
corridor. Vispecta opens it at Island #1 (station 6+083 on the northbound alignment).
